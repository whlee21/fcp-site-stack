# Contract — Workspaces

**Base**: `/api/v1` · **Auth**: Keycloak Bearer (R3) · 출처: 001, 011

모든 응답은 **메타데이터·참조만** 담는다. 데이터 계층 내용은 어떤 엔드포인트로도 반환하지 않는다.

| Method | Path | 설명 | 요구 롤 | 근거 |
| --- | --- | --- | --- | --- |
| `GET` | `/workspaces` | 목록. `lifecycle_state`, 준비중 경과 기간 포함 | 조회자 이상 | 011 FR-056 |
| `POST` | `/workspaces` | 생성. `slug`·`type` 필수, 유형별 입력 분기 | 플랫폼 운영자 | 001 FR-001~003, 011 FR-003 |
| `GET` | `/workspaces/{slug}` | 상세. 계층군 구성과 제한 대상 여부 포함 | 배정 사용자 | 011 FR-009~012 |
| `PATCH` | `/workspaces/{slug}` | 설정 변경(소스 커넥션·주기·파라미터) | 플랫폼 운영자 | 001 |
| `DELETE` | `/workspaces/{slug}` | 소프트 삭제. 스키마 즉시 삭제 금지 | 플랫폼 운영자 | 001 FR-022 |
| `POST` | `/workspaces/{slug}:restore` | 보존 기간 내 복구 | 플랫폼 운영자 | 001 |
| `POST` | `/workspaces/{slug}:discard` | 준비중 워크스페이스 명시적 폐기 | 플랫폼 운영자 | 011 FR-055 |
| `GET` | `/workspaces/{slug}/layers` | 계층군·계층 목록과 제한 여부 | 배정 사용자 | 헌법 v4.2.1 |
| `POST` | `/workspaces/{slug}/source-connections` | 커넥션 등록. 저장 전 연결 확인 | 플랫폼 운영자 | 001 FR-002 |

## 거부해야 하는 요청

계약의 절반은 "무엇을 거부하는가"다. 아래는 **반드시 4xx** 여야 한다.

| 요청 | 응답 | 근거 |
| --- | --- | --- |
| `slug`·`type`·`target_schema_*` 변경 | `409 Conflict` | 001 FR-013, 011 FR-002 |
| 중복 `slug` (보존 기간 내 삭제분 포함) | `409 Conflict` | 001 FR-005 |
| 내부망 밖 소스 커넥션 주소 | `422` | 001 FR-006, 헌법 I |
| 유형이 허용하지 않는 입력 | `422` | 011 FR-003 |
| 참조 자산 관리 유형에 환자 데이터 계층 생성 | `422` | 011 FR-005 |
| 정리되지 않은 워크스페이스가 있는 상태의 삭제 | `409` | — |
| 데이터 계층 내용 조회 시도 | **엔드포인트 없음** | 헌법 II·IV |

## 응답 규칙

- `410 Gone` 대신 소프트 삭제 상태를 `retention_state` 로 표현한다 — 복구 가능성이 상태다
- 오류 본문은 사유 코드와 요약만. 원천 값·환자 식별정보를 담지 않는다(헌법 III)
- 페이지네이션은 커서 기반. 전체 목록을 한 번에 반환하는 경로를 두지 않는다(헌법 IV 대용량 금지)
