# Contract — Roles

**Base**: `/api/v1` · 출처: 013

**롤 객체와 사용자 계정은 Keycloak 소유.** 이 API는 카탈로그(의미)와 배정 연결만 다룬다.

| Method | Path | 설명 | 요구 롤 | 근거 |
| --- | --- | --- | --- | --- |
| `GET` | `/roles` | 카탈로그. 스코프·허용·금지 행위·정의 근거·부여 가능 여부 | 배정 사용자 | 013 FR-001·002·005 |
| `GET` | `/roles/{key}/holders` | 보유자 목록 | 운영자·감사자 | 013 FR-032 |
| `GET` | `/users/{id}/assignments` | 사용자 전체 배정 현황 | 운영자·감사자 | 013 FR-031 |
| `POST` | `/workspaces/{slug}/assignments` | 워크스페이스 스코프 배정 | 플랫폼 운영자 | 001, 013 |
| `DELETE` | `/workspaces/{slug}/assignments/{id}` | 회수 | 플랫폼 운영자 | 013 FR-033 |
| `POST` | `/assignments/global` | 전역 롤 배정 | 플랫폼 운영자 | 013 FR-010 |
| `GET` | `/audit` | 감사 이력. 제한 롤 변경·제한 계층 조회를 구분 조회 | 감사자 | 013 FR-033~036 |

## 거부 규칙

| 요청 | 응답 | 근거 |
| --- | --- | --- |
| 카탈로그에 없는 롤 배정 | `422` | 013 FR-003 |
| Keycloak에 없는 사용자·롤 배정 | `422` | 001 FR-032 |
| **연구자 롤 배정** | `422` | 013 FR-029, 헌법 범위 경계 |
| **프로젝트 개설자·참여자 롤 배정** | `422` | 013 FR-029, 헌법 v4.2.1 |
| 마지막 전역 롤 보유자 회수 | `409` | 013 FR-014 |
| 플랫폼 운영자 롤만으로 제한 계층 데이터 조회 | **엔드포인트 없음** | 013 FR-011 |
| 감사자 롤의 설정 변경 | `403` | 013 FR-013 |

## 권한 판정 규칙

- 판정 근거는 **카탈로그와 일치**해야 한다. 카탈로그에 없는 허용을 코드가 부여하면 안 된다
  (013 FR-004) — 이는 계약 테스트로 검증한다
- 워크스페이스 스코프 롤은 **전이되지 않는다**. A의 제한 롤로 B에 접근 불가 (013 FR-015)
- Keycloak 비활성화 후 차단까지 **5분 이내** — 캐시 TTL + 토큰 수명의 합이 이 값을 넘지 않아야
  한다 (001 SC-011, R3)
- 제한 롤 부여·회수와 제한 계층 조회는 **다른 감사 카테고리**로 기록 (013 FR-034·035)
